# NETWORKWALKS – WEEK 2 PROJECT MODULE 1
## Footprinting with Multiple Kali Linux Tools

### 1. Project Overview

This repository documents the practical work completed for **Week 2 – Project Module 1 (W2-PM1)** of the NetworkWalks Cybersecurity Training Programme.

The project focused on website footprinting and information gathering using six command-line tools available in Kali Linux.

The exercise involved collecting publicly available information about the authorised assessment target, examining DNS records, analysing HTTP responses, identifying web application firewall technologies, and detecting website technologies.

**Assessment Target:** `networkwalks.com`  
**Operating System:** Kali Linux  
**Project:** W2-PM1 – Footprinting with Multiple Kali Tools

---

### 2. Project Objectives

The objectives of this exercise were to:

- Perform domain information gathering.
- Examine DNS records and domain resolution.
- Retrieve website response information.
- Identify possible Web Application Firewall (WAF) technologies.
- Discover the technologies and web server information used by the target website.
- Document the findings with terminal screenshots.

---

### 3. Tools Used

Six Kali Linux tools were used during this exercise.

| No. | Tool | Purpose |
|---|---|---|
| 1 | WHOIS | Retrieve publicly available domain registration information. |
| 2 | DIG | Query DNS records and obtain domain-related information. |
| 3 | NSLOOKUP | Perform DNS queries and resolve domain names. |
| 4 | cURL | Retrieve website responses and inspect HTTP headers. |
| 5 | WAFW00F | Check for the presence of a Web Application Firewall. |
| 6 | WhatWeb | Identify website technologies, server information and related components. |

---

### 4. Methodology and Practical Activities

The following activities were performed against the project target.

#### 4.1 WHOIS – Domain Information Gathering

WHOIS was used to retrieve publicly available registration information associated with the target domain.

#### 4.2 DIG – DNS Information Gathering

DIG was used to query DNS records and examine domain-related information.

#### 4.3 NSLOOKUP – DNS Resolution

NSLOOKUP was used to investigate DNS information and resolve the target domain.

#### 4.4 cURL – HTTP Response Analysis

cURL was used to communicate with the target website and inspect information returned by its web server.

#### 4.5 WAFW00F – Web Application Firewall Detection

WAFW00F was used to check whether the target website was protected by a Web Application Firewall.

#### 4.6 WhatWeb – Website Technology Identification

WhatWeb was used to identify technologies and components associated with the target website.

The assessment identified technologies including:

- Apache web server
- WordPress
- jQuery

---

### 5. Key Observations

The footprinting exercise demonstrated how different reconnaissance tools can collect different categories of publicly available website information.

The WhatWeb assessment identified Apache and WordPress, alongside jQuery and other website technologies.

The individual tool outputs were reviewed and documented as part of the practical exercise.
